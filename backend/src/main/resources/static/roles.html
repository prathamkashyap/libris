Access

Access model

Server-enforced application roles. This reference does not imply configurable permissions.

Administrator

Can manage team accounts as well as catalog, member, circulation, analytics, and report routes.

Librarian

Can manage catalog, member, and circulation routes, and view analytics and reports. Team-account routes remain administrator-only.

Student

Can use the personal student dashboard, view the catalog, and access their own borrowing information.

How authorization works

The backend authorizes API URL patterns for every request. The interface adapts navigation for clarity, but it is not the security boundary.
