Libris - internal package dependency graph

Built directly from the actual import com.example.lms.* statements across all 88 backend source files (github.com/prathamkashyap/libris, branch main). Edge labels show "files that import it / total files in that package". Line thickness scales with that ratio.

Entry / boundary layer — controller, config, security Business logic — service, event Cross-cutting support — exception, util Data access / transfer — dto, repository Domain model — entity

Worth a look before you build on top of this

  • ⚠ Layer-skipping (dashed coral): three files reach past the service layer directly — BorrowRecordController calls a repository directly, AuditController imports an entity directly, and the util class CurrentUser reaches into a repository. Everywhere else, controllers go through services (14/14 files) and services own all repository/entity access — these three are the exceptions.
  • ↻ Circular reference (dashed amber): service and event depend on each other — services publish EntityAuditEvent (5 of 11 service files), and AuditEventListener in the event package calls back into AuditService. Not necessarily wrong (it's a standard publish/listen pattern for audit logging), but it's the one place import direction isn't strictly one-way.
  • entity and dto have effectively zero outgoing internal dependencies (dto touches entity in exactly 1 of 27 files) — they're clean, which is good: it means you can change business logic without rippling into your data shapes.
  • repository is the most depended-on package after entity (5 packages reach into it), which tracks with it sitting right above the domain model.

No package.json in the repo — the frontend is vanilla ES modules with no bundled dependency tree to graph. External backend dependencies (from backend/pom.xml): Spring Boot 3.5 starters (web, data-jpa, validation, security, oauth2-client, actuator, cache), springdoc-openapi 2.8.6, Flyway (core + mysql), MySQL connector, H2 (test/dev), and logstash-logback-encoder — all under Java 21.
